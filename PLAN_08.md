## Items
1. **Jobs are owned.** At `run`, record `owner` in meta.json: $HC_TERMINAL_ID, else $HERDR_PANE_ID, else null (also expose `AGENT_SHELL_OWNER` env to override, for tests and scripts). `list` and `clean` default to the caller's own jobs only (same owner; a caller with no identity sees only ownerless jobs). `--all` on both means every job on the machine; `list --all` shows an OWNER column / `owner` JSON field. Jobs created before 0.6.0 have no owner: they are only listed and cleaned with `--all`. Commands that take an explicit job id (show, tail, check, kill) still work on any job. `clean` prints how many jobs were removed and how many other-owner jobs it left alone (JSON: `removed`, `removed_ids`, `skipped_other_owner`). Update help, README and tests (two owners must never touch each other's records by default).
2. **Heartbeats actually arrive.** `hcx send --if idle` compares the status exactly and refuses agents whose status is `done` (the normal idle state of claude and muse), `silent` (opencode) or unknown. Replace `--if idle` for heartbeats with an own pre-check: read the target's status through `hcx ls --json` (match the terminal address or name; one call per heartbeat, 5 s timeout) and send the heartbeat unless the status is `working` or `blocked`. A busy skip counts as skipped, not failed. Completion keeps sending unconditionally. Keep everything else about the hcx call (--agent-only --no-footer --json, no retry after a send that may have landed).
3. **Quiet old-server route.** The `herdr agent prompt` route reports `server_not_running` on every notify when no old herdr server runs. Check once per process whether the herdr socket exists / the server answers; if not, skip that route silently. Failure details shown in `progress_notify` / `notify_detail` must describe only routes actually tried; when the route that finally delivered succeeded, earlier skipped-route noise is not shown.
4. **Heartbeat counters.** Status and show/check output (text and --json) report `heartbeats_sent`, `heartbeats_skipped_backoff`, `heartbeats_skipped_busy`, `heartbeats_failed` and keep `heartbeats` as an alias of sent. `last_heartbeat_detail` stays. Show prints one compact line, e.g. `heartbeats sent 2, skipped 3 (backoff 2, busy 1), failed 0`.
5. **Honest notify outcomes.** A completion notify that times out (exit null / kind timeout) may have landed: record outcome `unconfirmed` with the timeout in the detail, not `failed`, and `check` must not fail the job for it. Raise the completion send timeout to 30 s (heartbeat 10 s). `check` prints unconfirmed as `ok notify: unconfirmed (delivery not verified)` instead of a plain `ok`; `delivered` stays `ok notify: delivered`.
6. **command_string round-trips.** Store/show `command_string` as a POSIX shell-quoted string of the argv (single-quote any argument with characters outside [A-Za-z0-9_@%+=:,./-]) so copy-paste reruns the same command. The `command` array is unchanged.
